## Diploma

The public diploma includes four levels with four parts each, reading and Arabic browser narration, part exams and exactly 50 questions per level exam. An 80% pass unlocks an educational completion certificate for that exam. Practice results are stored on the current device; they are not cloud-verified credentials.

The Arduino lab executes fixed ATmega328P firmware through avr8js at 16 MHz. It supports a series-resistor LED circuit, active-low button input, software PWM, and a teaching safety interlock. It does not compile arbitrary C++, connect to physical hardware, or certify electrical safety.
